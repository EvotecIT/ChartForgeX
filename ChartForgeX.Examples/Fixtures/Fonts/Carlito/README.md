# Carlito review fixtures

These unmodified regular and bold fonts are example/validation assets. They are not included in the ChartForgeX runtime package. Gallery and benchmark fixtures explicitly register them so the two rendering paths use the same known faces; the engine itself does not download fonts.

Source: [Google Fonts Carlito at revision 3dd78844021e948ceb633d1dcee3f7885561b5d9](https://github.com/google/fonts/tree/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/carlito). The font copyright and SIL Open Font License 1.1 are retained in [OFL.txt](OFL.txt).

# Migrating ChartForgeX applications

Use the [current migration guide](v2/migration.md) when updating an existing application. It covers the unified theme and data APIs, package ownership, static rendering, HTML adapters and consumer qualification.

Start with these sections:

- [Unified authoring contracts](v2/migration.md#unified-authoring-contracts) for immutable themes, explicit light/dark modes, stable series identities and typed observations.
- [Optional package migration](v2/migration.md#optional-package-migration) for canvas, factual blocks, stories and animation.
- [Chart export and presentation changes](v2/migration.md#chart-export-and-presentation-changes) for shared SVG/PNG preparation, frame settings and independent card, plot and mark geometry.

Keep the ChartForgeX packages on the same coordinated version and rebuild compiled callers. For a new application, follow the [README](../README.md) and [API conventions](v2/api-conventions.md).

ChartForgeX

Charts and a data grid that follow each other

Four chart families and a CanopyX grid show the same records. Click a mark to filter the grid, drag across the trend for a date range, or select rows to mark them in every chart. Remove the grid's chip and the chart lets go too.

Example data: 148 illustrative change records for October 2026, not real releases.

Changes this week

Records per day by kind. Click a segment to filter by its day and kind; Shift+click adds.

Daily trend

Hover for every series at a date. Drag across days to filter that range; the heatmap follows.

Products by week

Records per product and week, by the Monday that starts it. Click a cell to filter.

Support windows

The current release is banded and open support fades. Click a release to filter.

Records

A CanopyX data grid. Select rows (Ctrl or Shift for several) to mark them in every chart.

How it's wired

Marks carry record keys and fields from ChartMarkOptions; grid row ids are the same keys. This is the page's whole linking script:

// Four ChartForgeX charts and one CanopyX grid of the same records follow each other: one call per pair.
document.addEventListener("DOMContentLoaded", () => {
  const grid = document.getElementById("records");                    // the element holding the CanopyX grid
  const chart = id => CfxEnhance.get(document.getElementById(id));    // the LinkedView API of the chart inside

  CfxLink.connect(chart("week"), grid, { field: ["day", "kind"], sourceLabel: "Changes this week" });
  CfxLink.connect(chart("trend"), grid, { field: "day", sourceLabel: "Daily trend" });
  CfxLink.connect(chart("heatmap"), grid, { field: ["week", "product"], sourceLabel: "Products by week" });
  CfxLink.connect(chart("support"), grid, { field: "product", sourceLabel: "Support windows" });

  // Chart to chart: brushing the trend highlights the heatmap cells that hold the same records.
  CfxLink.connect(chart("trend"), chart("heatmap"), { mode: "highlight", sourceLabel: "Daily trend" });
});

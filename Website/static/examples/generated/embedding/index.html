Use it in your page

Keep the chart small. Let HTML do the layout.

Prepare each row against one shared scale, then export with fluid width and page font properties. Keep the SVG inline so links and CSS variables reach the host page.

Shared-domain strip source
var scale =
    ServerRenderedRecipe.SharedScale();
// Bounds: 1 Jan 2026 to 1 Jan 2027.
var row =
    ServerRenderedRecipe.CreateStrip(1);
var track = row.PrepareStrip(context, scale);
var axis = scale.PrepareAxis(axisContext);
var policy = new VisualSvgOptions("release")
    .WithFluidWidth()
    .WithFontVariables(
        "--page-font", "--chart-font-size");
var svg = track.ToSvg(policy);
// HTML owns the label. Reuse this scale.

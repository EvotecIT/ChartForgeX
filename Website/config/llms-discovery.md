## ChartForgeX documentation

ChartForgeX renders charts, dashboards, maps, topology and supported Mermaid diagrams in .NET. Use the surface guide to choose an output format. PowerShell examples use ImagePlayground; the command reference describes that module's ChartForgeX integration.

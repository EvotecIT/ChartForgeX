ChartForgeX is a dependency-free .NET rendering engine for charts, report grids, visual blocks, canvases, topology, hierarchy, and optional interactive HTML.

Use the [.NET library](/docs/install/) from application code, the [command-line tool](/docs/cli/) to validate and export Markdown visuals, or the [VS Code extension](/docs/editor/) to preview them while editing. The [playground](/playground/) lets you try supported markup and Mermaid diagrams in the browser.

Then [choose a rendering surface](/docs/choosing-a-surface/) and follow a [runnable example](/examples/). The [chart gallery](/gallery/) shows native chart output, while [Mermaid support](/mermaid/) lists diagram families and their supported syntax boundaries.

ChartForgeX is a dependency-free .NET rendering engine for charts, report grids, visual blocks, canvases, topology, hierarchy, and optional interactive HTML.

Start with [installation](./install/) and [your first static chart](../examples/static-chart/). Then [choose the surface](./choosing-a-surface/) that matches the information you need to communicate, or browse the [curated examples](../examples/).

ChartForgeX is a dependency-free .NET rendering engine for charts, report grids, visual blocks, canvases, topology, hierarchy, and optional interactive HTML.

Use the [.NET library](./install/) from application code, the [command-line tool](./cli/) to validate and export Markdown visuals, or the [VS Code extension](./editor/) to preview them while editing. The [playground](https://chartforgex.com/playground/) lets you try supported markup and Mermaid diagrams in the browser.

Then [choose a rendering surface](./choosing-a-surface/) and follow a [runnable example](../examples/). The [chart gallery](https://chartforgex.com/gallery/) shows native chart output, while [Mermaid support](https://chartforgex.com/mermaid/) lists diagram families and their supported syntax boundaries.
